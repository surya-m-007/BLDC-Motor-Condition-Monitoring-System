# Intelligent  BLDC Motor Drive with Real-Time Condition Monitoring, Energy Analytics and Predictive Maintenance

## Project Overview

This project presents an intelligent Industrial BLDC Motor Monitoring System using ESP32, IoT, MATLAB/Simulink and Blynk Cloud.

The system continuously monitors the motor's operating conditions and predicts maintenance requirements using real-time sensor data.

---

## Features

- Real-time Voltage Monitoring
- Real-time Current Monitoring
- Power & Energy Analysis
- Temperature Monitoring (DS18B20)
- Vibration Monitoring (MPU6050)
- Motor Health Score Calculation
- Fault Detection
- Predictive Maintenance
- OLED Display
- Blynk IoT Dashboard
- MATLAB/Simulink Validation

---

## Hardware Components

- ESP32 DevKit V1
- BLDC Motor
- BLDC Driver
- ACS712 Current Sensor
- Voltage Sensor Module
- DS18B20 Temperature Sensor
- MPU6050 Accelerometer
- OLED Display
- 24V SMPS
